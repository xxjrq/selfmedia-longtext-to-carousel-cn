# 长文转图文分页稿

![长文转图文分页稿推广图](assets/promo-1600x900.png)

把一篇有价值的中文长文变成读者愿意连续滑动的分页稿：你会得到封面钩子、每页一个重点的文案，以及能交给设计执行的配图需求。它尤其适合中文小店经营者、小说作者和自媒体创作者复用原创内容。

这是一个纯 Markdown Skill：不调用第三方 API、不需要浏览器登录，也不生成图片成品。

## 输入与结果

输入一份用户原创或已获授权的完整长文，以及目标受众；还可补充平台、页数、语气与转化目标。结果是 6–10 页的文字分页稿，包含封面钩子、逐页文案、配图需求、事实/建议区分和发布前核对。

缺少完整正文、授权说明或目标受众时，Skill 会指出缺失并请求补充，而不会编造内容。

## 使用示例

```text
把以下用户原创长文面向“经营社区烘焙小店、希望提高复购的店主”改为图文分页稿。
要求：8 页，务实、友好；保留原文数字，不新增事实。

（粘贴完整长文）
```

详细工作流与固定交付格式见 [SKILL.md](SKILL.md)。成功与失败输入样例在 [fixtures](fixtures/) 中。

## 自测

在本目录直接运行：

```bash
python3 scripts/self_test.py
```

该命令验证发布结构、关键字段、图标尺寸及成功/失败样例的预期声明；它不把静态样例伪装成真实内容生成验证。真实行为需以授权长文和目标受众进行实际调用确认。
